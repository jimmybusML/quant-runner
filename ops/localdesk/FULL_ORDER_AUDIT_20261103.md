# Mac 控制台逐场实战账本与盘口证据可视化｜2026-11-03

## 用户直接要求

原战绩首页只有 ROI/总数，没有比赛、双方水位、买入方向及下单价、赛果和结算输赢，造成无法复盘亏损。用户明确要求**全部比赛逐笔**的盘口及下注决定可视化。不得新增交易 Gate、筛选规则、数量上限，不能事后补假水位。

## 已安装功能（Mac 本机）

- 保持原首页 **战绩／运行／设置**，点击模型战绩后新增“逐场订单与盘口明细”列表，并可搜索联赛、中文球队、比赛编号，显示全部订单的分页导航、最近/上周/本周对应口径及赢/输/待结的纯视图筛选。界面分页只是浏览方式，不删除、去重或过滤掉真实正式 TG 订单。
- 明细逐行包含：中文联赛、主客中文队名、TG 实发时间、主队盘口线与**香港水位**、客队盘口线与香港水位、我方选择的方向/让球、真实下单香港水位、赛果比分、全赢/半赢/走水/半输/全输、每单净收益；同时标明报价距发单间隔、同场多笔数量和来源没有验证的旧单。
- 点任意订单打开单场复盘层：双方盘口与选中的水位/欧赔、TG 发单时间与历史报价时间、报价到发单时长、当时模型预计 EV（只展示研究诊断，**没有新增 EV Gate**）、比分、输赢、净收益、所有相同比赛订单及各自回报、两条水位变化曲线与逐次盘口线记录（盘口线变化需分开理解），原始 TG 消息文本，收据 ID 和来源证据放在折叠详情内。
- Chrome Playwright 实际点击验证表格、单场弹层、M1/MR1 水位路径、M3 无另一侧报价、M4 研究假设；搜索、翻页、上周 269 单 MR1 与亏损订单 131 单筛选、390px 手机屏不出现页面横向滚动；浏览器无 JS 错误。
