# Crown 真实收据报价新鲜度与 AH 两侧结算诊断

## 问题及与旧研究的区别

本实验只核验一个执行经济假设：Crown 实际 HTTP 收件中，盘口源事件已经过去多久（`received_utc - AH_source_event_utc`），是否与同一条真实赛前报价下 AH 两侧的实际结算回报相关。报价年龄是双边共同的报价可用性/陈旧度变量，本身不指示买哪一侧；因此没有用它造下注方向或筛单规则。

对照 R53，旧研究已报告报价源年龄的年度及实收描述值，并研究 T24→T12 报价时点对同一未来侧的历史结算敏感度；R57 已逐一验证真实收件后续 T6/T3/T1 报价，并研究预测同线降价与原始 T12 结算；R58 已研究 Crown 价格方向、赔率不足和 favorite/underdog 伪对照；更早实收时间稳定性研究也测过首末价与方向结算。本轮的唯一新增检验，是在同一份经过哈希核验的实际收据中，直接按“源事件到 HTTP 到达”延迟分层，核算同一报价两侧各自的正确 AH 结算收益。没有重跑水位涨跌模型、Crown 特征 Ridge、EV 分位阈值或 R57/R58 选边模型。

## 数据与计算

- 输入：既有 M8 真实赛前 Crown HTTP 独立审核档案 `m8_batch_actual_receipt_independently_audited_20261118.jsonl`，输入 SHA256 `f542c2ae61ff1fc0d5a8f51942ed74c9ed69ff4a2be19ce39ad2bb411b049bf0`。
- 取同档案 E 行作为 quote-level carrier，去重后 1,230 个 FID；均为 `actual_http_receipt`，每行具备 raw response 与 snapshot SHA，来自 2026-10-09 至 2026-11-13。原始审核记录涵盖 T12 1,172 场及 T18 58 场；所有收到时间早于开球。没有把历史事件回取当成实收。该 1,230 FID 池与前轮 A–L 候选设计同源，不是新前瞻验证。
- 对每一场实际收到的 Crown 主队线与双方十进制赔率，独立按主、客两侧分别结算；AH 客队使用反号让球线，四分之一盘拆半注腿。对现有 E 侧归档结算行逐场匹配。
- 盘型 favorite 依据 signed AH 让球线确定；零盘以较低赔率边作为价格 favorite 代理。受让边是另一方。此身份只用于描述，不是模型选择。
- 预先用于描述的源事件年龄分组为 `<15 分钟 / 15–60 分钟 / 1–6 小时 / ≥6 小时`。分组仅用于描述性审视，不是出单 Gate。还单独提供原八组外唯一 FID 的事后归属表；该成员身份在收据时未必已知，不能视作可执行过滤。

## 结果

全部 1,230 场真实收据上，盘口 favorite 侧为 **−69.390U / −5.641% / MDD 74.150U**；另一侧为 **−27.815U / −2.261% / MDD 38.940U**。以未来冻结八组成员作事后唯一 FID 扣除后，977 场八组外样本中 favorite 为 **−54.425U / −5.571% / MDD 56.275U**，underdog 为 **−23.100U / −2.364% / MDD 29.725U**。这些是对每场分别下注一侧的诊断账，不是任何候选方法订单，也不能把两侧收益相加成组合策略。

| 实收报价年龄 | 场数 | 全池 favorite 净U / ROI | 全池 underdog 净U / ROI | 八组外 favorite 净U / ROI | 八组外 underdog 净U / ROI |
|---|---:|---:|---:|---:|---:|
| <15分钟 | 35 | +3.775 / +10.786% | −6.740 / −19.257% | +4.505 / +17.327% | −6.970 / −26.808% |
| 15–60分钟 | 221 | −4.050 / −1.833% | −10.655 / −4.821% | −10.695 / −6.111% | −0.055 / −0.031% |
| 1–6小时 | 294 | −25.135 / −8.549% | +5.000 / +1.701% | −17.390 / −7.496% | +1.780 / +0.767% |
| ≥6小时 | 680 | −43.980 / −6.468% | −15.420 / −2.268% | −30.845 / −5.670% | −17.855 / −3.282% |

`<15分钟` 八组外 favorite 的 +4.505U 看似正向，但仅 26 场，且正贡献集中在 W41–W44：15 场 +6.275U；W45–W46 合计 11 场 −1.770U。它是结果出来后观察的窄切片，样本小且较晚两周回落，不构成稳定利润证据。≥6小时为最多的一档（680/1,230）；源报价延迟最长 26,934.317 分钟（约18.7天），中位 518.854 分钟（约8.65小时）。较旧的报价本身未给出可执行方向，favorite 与 underdog 两侧在大样本上均亏。

唯一实收年度是 2026。没有 2024、2025 的真正 HTTP receipt + source timestamp 成对历史数据，因此不能训练较早年度、再检验后续年份；历史盘口事件源时间不足以填补这项缺口。回报按 2026-W41–W46 逐周保存在 JSON；没有获得成交/拒单/实际填单记录，所以收到快照只证明观测到报价，不证明可以按该价成交。

## 结论

这项新鲜度诊断没有发现可证明的独立新增盈利来源。少量 `<15分钟` favorite 价样本为正，但仅 26 个八组外 FID、六周内后半段回撤，且按原八组归属的筛选是事后标注；其他大样本年龄区间没有同方向持续表现。现有数据缺少多年度真实收据的源事件年龄、实时报价后的订单提交/成交/拒单/部分成交和价格滑点记录，因此无法识别“真实可执行合理价”或证明陈旧报价可获利。

不得把年龄分组升级为正式策略、门槛或执行条件；原八组和生产行为不变。
