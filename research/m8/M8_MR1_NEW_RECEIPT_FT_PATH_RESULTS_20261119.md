# M8 / MR1 新收据的真实赛果与 Crown 原始盘口路径（2026-11-19）

本轮以原M8研究库存外175个MR1赛前Crown AH收据FID为范围，延续上一轮已同意的只读补充核验。不修改原八组会员、信号、配置、MR1采集、TG或正式账本。

## 一、实际结果

按上一轮审计固定截至2026-11-19 04:30 UTC（北京时间12:30）的开球时间：
- 175场全部在MR1赛事库有联赛、双方与开球时刻。
- 90场在该时点已到开球时间；85场尚未到开球时间。开球到达不等于完场。
- 对90场使用现有已授权TotalCorner比分接口/match/view做**仅比分证据查询**：首次查询83场满足status=full、FID、球队、开球时刻一致；7场异常包括3条TOO_MANY_REQUEST、1条TLS SSL异常以及3条源端非full状态。对4条请求异常保守复查后又有3场获得可信FT，1场仍非full。
- **最终86场有可信FT主客比分；4场仍不可核实完场**，均为Ukraine Persha Liga的FID 204418687、204574569、204574571、204574573；不能把源端status=39或null解释为最终比分，也不得根据已显示进球数字假定终场。
- 原始API响应留在Mac本地研究目录，每次成功接收均保存SHA256和观察时间，公开研究只提交每FID的证据哈希、赛果和状态，不提交原始body或token。
- 86场只是**可以证实赛果的新增报价比赛**；还未生成可复现的原八组赛前预测方向，故本轮新增可结算M8策略订单0笔，净U/ROI不适用。不得把86场视作TG正式实战。

## 三、MR1 原始快照的新增研究价值

深入解析MR1保存的Crown bookmaker odds原始HTTP response：其中的asian_list按源报价发生时间列有多个盘口/双边赔率事件，远超过MR1单条AH概览字段。对上述90场T1档进行一致性核验：

- 90场T1 snapshot SHA和原始HTTP response SHA均通过；0条需要排除的未来source事件。
- 90场的T1快照实际HTTP收件均在开赛前60–75分钟之间，意味着**收件时仍早于精确T−1小时**；不能假装预知收到后至T−1小时的后续变化。
- 81场在收件时保存的原始Crown数据中可追溯到T−6小时或更早的报价。
- 63场在T−6至T−1小时窗口已保存至少两条报价事件，并且有实际盘口线或水位变化。
- 上述结论与此前仅按T6/T3/T1多个收据快照计数不同：它证明**单个赛前收件时已经具备可复核历史运动轨迹**，具有后续M8市场路径研究价值。
- 但是冻结八组的历史T−1小时路径分类/比分概率特征，不等于收到于T−67分钟的MR1市场路径前缀。**不得以新路径前缀或旧赛后回取路径直接宣称重现原八组当时可成交信号**。
