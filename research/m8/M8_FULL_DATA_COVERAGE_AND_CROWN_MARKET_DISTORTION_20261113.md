## 2. 不挑盈利组合：36,178场全量市场结构对照
对全部36,178场都纳入市场库存，比较当时Crown AH收盘盘口的机械让球方/受让方收益；**没有事后按输赢删除样本**。为定义热门方/受让方，零让球盘口无法区分双方，共4,696场不属于机械热门/受让两侧收益比较，但仍保留在36,178场整体库存中。两侧在同一结构下为独立1U反事实研究，不是正式投注。

| 历史市场结构 | 机械受让方ROI / 样本 | 机械让球方ROI / 样本 |
|---|---|---|
| 全部非零AH盘口 | -2.215% / 31,482场 | -3.811% / 31,482场 |
| AH开盘到收盘盘口向让球方加深 | **-0.036% / 10,385场** | **-5.806% / 10,385场** |
| AH盘口向受让方移动 | -1.635% / 5,709场 | -4.191% / 5,709场 |
| AH盘口开收到收盘不变 | -3.900% / 15,388场 | -2.323% / 15,388场 |
| 最终让球深度1.75–2.0球 | **+3.094% / 1,702场** | -8.887% / 1,702场 |

可见AH盘口向让球方加深时，机械买让球方在同样历史样本上明显更差；然而反向机械买受让方**整体仍然不盈利**（-0.036%）。这证明一段时期的热门方历史表现差，并不能推出另一侧必然有稳定可交易正EV。

## 4. 研究方法局限
- 历史Crown接口2026年赛后回取早年盘口，即使open/close报价源事件时间早于开赛，也不是当时的HTTP实收；缺乏实际历史成交能力保证。
- 原49联赛全部赛程78,130场仍有大量Crown盘口缺失，36,178场是**可核实市场数据覆盖**，不是赛事全集或全量盈利表现。缺失机制可能偏向特定年、联赛、盘口可用性。
- 直接以历史完整赛事盘口分组发现优势，属于研究性观察；这种分组或研究阈值未经用户批准，不是M8生产筛选条件；不得把未被选中的比赛从正式出单逻辑删去。
- 把所有机械价格优势与旧M7参考方向分别核算，M8研究与M7、M1、MR1等模型正式身份完全独立。当前**没有已经被验证可重复的正ROI**，不能把“改善负收益”当盈利成功。
