# M8 Dynamic Elo × Crown AH 前推研究

**研究性质：** 历史研究回放；不属于正式策略、Telegram 派单或正式账本。原八组成员与规则没有改动。

## 结论

在现有 M8 Crown T1 路径上，联赛内动态 Elo 没有形成冻结八组之外的正净利润。2024–2026 北京时间开赛年度的 21,455 个八组外唯一 FID，在三个固定配置中都为负；采用模型预测的期望收益大于 0 才投注、否则不下注的实验方案也都为负。2026 年真实 Crown HTTP 收据只有 Crown-only 配置有可结算交集：84 场、−0.200U；这批收据没有与可重建 Elo 特征的可信赛果 FID 交集，不能据此宣称 Elo 已通过真实收据验证。

**没有发现可加入原八组的独立盈利订单来源。** 选择方向模型虽然有少量与 Crown-only 不同的方向，但在完整八组外库存及实际收据上均未产生正收益。以下全部成绩使用真实 Crown AH 线和双边赔率，四分之一盘口拆成两条半注结算。

## 固定实验方案

1. Elo 按 `(联赛ID, 球队ID)` 独立维护，初始分 1500、K=20、主场更新加成 65；仅以胜/平/负更新，不用净胜球乘数。目标行只使用其 UTC 开赛日前至少两个日历日已结束的比赛；同 UTC 日期赛果批量更新，防止同日比赛互相泄漏。
2. AH 目标为五态结算概率：全输、半输、走水、半赢、全赢。目标 Crown 盘口线与主客赔率均不进入该场比分结果标签。
3. 每个目标年度只用之前年度拟合：2024 训练 2019–2023（11,217 场）；2025 训练截至 2024（20,367 场）；2026 训练截至 2025（30,561 场）。多分类 softmax、训练样本标准化、固定 L2=1；测试年度没有调参。
4. 方向回放每场各选 home/away 中预测净收益较高的一侧，1U；另单独计算一个非生产“可不下注”实验：仅当较高的预测净收益严格大于 0U 才出单。0U 是收益数学上的盈亏平衡点；这只是本轮诊断，没有写入任何 Gate。
5. 口径明确区分：历史 T1 为 Crown 历史 source-event 回放，不是当时实际收件；MR1 行仅在原始响应 SHA、响应内 Crown AH 双边报价及开赛前收件时间核验通过后，才进入真实收据子集。模型概念在 M8 已有结果研究之后形成，所以年度前推可以防止模型训练穿越，但 2024–2026 不是研究设计盲测期。

### 配置定义

| 配置 | 赛前输入 |
|---|---|
| `CROWN_ONLY` | Crown AH 线、无水差主队隐含概率、市场 overround |
| `ELO_CONTRACT` | Crown AH 线、联赛内赛前 Elo 差 / 400 |
| `CROWN_PLUS_ELO` | 上述 Crown 特征与 Elo 合并 |

这些模型是历史球队胜平负信息的另一种评分法。它与攻防 Poisson 的目标构造不同，但并不是全新外部信息源；不能将结果解释为球队数据之外的独立情报。

## 市场基准、信息增量与八组并入成绩

在同一批 21,455 个八组外 FID 上，始终选择 Crown 双边赔率较低的一侧为 `−528.905U / −2.465%`。三个学习方向的全覆盖结果均比该简单市场方向更差，表明这组模型没有克服实际报价水差。

同一 FID 上，`ELO_CONTRACT` 相对 `CROWN_ONLY` 改变方向 441 场（2.06%）；这些变向场的 Elo 净值为 +0.760U、Crown-only 原方向为 −28.775U，变向收益差 +29.535U。`CROWN_PLUS_ELO` 改变方向 285 场（1.33%）；变向场本身 −1.685U，而 Crown-only 原方向 −14.685U，差 +13.000U。这表示 Elo 在少量两边选取上提供局部方向改善，但仍不足以改变全样本负收益结论，也未胜过低价侧基准。

五态概率指标同样很小：`CROWN_ONLY` NLL / Brier 为 1.291496 / 0.673036；`ELO_CONTRACT` 为 1.292053 / 0.673270（较差）；`CROWN_PLUS_ELO` 为 1.291442 / 0.673018（略好）。轻微的概率评分变化没有转成正净利润。年度内按 ISO 周重采样20,000次的净U 95%经验区间分别为 `CROWN_ONLY` [−1,058.265, −547.389]U、`ELO_CONTRACT` [−1,026.986, −516.735]U、`CROWN_PLUS_ELO` [−1,049.038, −530.038]U。此区间是回放分布描述，不校正多轮 M8 研究的选择偏差。

## 真实赛前 Crown 收据复核

- 对 MR1 档案中的 12,550 个报价尝试逐项核对原始HTTP响应 SHA，并在响应内寻找精确 Crown `asian_list` AH 线及主客水位。18 条响应/盘口匹配未通过，22 个ID出现赛事身份不匹配；未将它们当作有效报价。筛选后保留 1,598 个唯一 FID 的有效赛前 Crown 报价。
- 其中只有 84 FID 与独立 `verified_ft` 索引相交，并且这 84 个 FID 全部在冻结八组之外。选用每个 FID 最新收到、收件早于开球且原响应中能核对的 Crown 报价进行 Crown-only 结算。
- `CROWN_ONLY`：84 场、−0.200U、ROI −0.238%、MDD 1.000U；39 场在 2026-W45 为 −0.285U，45 场在 2026-W46 为 +0.085U。该小样本不是盲测或正式实战。
- 按当时拟合的 2026 `CROWN_ONLY` 预测 EV>0 才投注：28 场、−1.935U、ROI −6.911%；56 场不下注。
- `verified_ft` 的84场与 Elo 历史身份特征可连接的收据FID交集为0（收据中有1,178个报价FID能连到 Elo 历史赛前特征，但这批不在已验证FT集合内）。因此无法计算 Elo 或 Crown+Elo 的实收利润，报告为0场可评价；不以 Crown-only 结果代替 Elo 结果。

这些是真正赛前收到的 Crown HTTP 报价，但报价窗口此前已保存并参与项目研究，不是本轮研究设计以外的新盲样本，也不证明实际成交。

## 独立验证和局限

独立校验脚本不调用研究脚本的结算函数；它重读 Crown 行、比分FT、冻结FID和逐场预测，重新验证三配置共83,652条逐场预测行（每配置27,884个唯一FID）、21,455个八组外唯一FID、选边和每场AH净U。另从实际收据原文件复算84笔 Crown-only 单：原始响应 SHA、响应内皇冠报价、可信 FT 及 quarter-line 拆腿全部通过；独立重算为 −0.200U。独立执行输出见 `independent_verification_20261120.json`。

重要限制：

- 2024–2026结果已被此前 M8 多方向研究者观察；时间前推约束模型训练，不消除研究设计/假设选择造成的选择偏差。因此这些年度不是完全未见的研究试验期。
- 历史 T1 Crown 路径的实际 HTTP 收件时间不属于历史开赛前，事件时间回放不等于当时可执行。
- M8比分输入没有精确首次公开/系统接收时间；2 UTC 日 embargo 是保守的时序近似，仍不能证明历史上实际可得。
- Elo+ verified-FT 的实收FID交集为0，实收层面的 Elo 增量无法验证。
- 真实收据结算只有84场，且集中在两个 ISO 周，净额接近零不足以说明稳定性。
- 全覆盖和 EV>0 方案都是实验决策模式，不是生产规则。未改变原八组、M9、M1/MR1、生产模型、Telegram、账本、采集配置、调度或交易规则；没有派单、正式账本回写或生产工作流运行。
