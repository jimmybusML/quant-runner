## 二、亚洲大小球的预期现金流：贝叶斯为何方向统一转Under

同场9,908场历史Crown T−12h赛后回取源事件报价，五大俱乐部联赛2019/20—2025/26，R5和R8输入、盘口和赔率完全相同。原R5采用后验期望进球点均值，R8将独立逆伽马潜在攻防参数使用Sobol256次后验积分再选OU边。

对完整四分之一盘口两条腿，加权Over全赢概率为W，全输概率为L：
EV(Over) − EV(Under) = 十进制Over赔率×W − 十进制Under赔率×L。
由此分离：
- **后验不确定性效应**＝混合全部后验进球强度的EV差 − 相同Sobol样本平均进球强度的单一泊松EV差；
- **样本均值偏移效应**＝上述样本均值下单一泊松EV差 − 原R5后验点均值下单一泊松EV差。

| 同场OU研究 | k1较弱先验 | k2中等先验 |
|---|---:|---:|
| R5点均值泊松OU净U | −126.085 | −148.560 |
| R8完整后验OU净U | −245.375 | −219.805 |
| 方向变化 | 1444次，全部Over→Under | 1361次，全部Over→Under |
| EV(Over)−EV(Under)平均变化 | −0.1305408 | −0.1141075 |
| **其中后验不确定性造成** | **−0.1204007** | **−0.1057239** |
| 其中有限Sobol样本均值偏移造成 | −0.0101401 | −0.0083836 |
| Over全赢概率平均变化 | −0.0274731 | −0.0237685 |
| Over全输概率平均变化 | +0.0401585 | +0.0353497 |

从**平均预期收益差的算术分解**看，约92%–93%是积分潜在比赛强度的不确定性造成，只有7%–8%属于样本均值微小偏移。k1全量9,908场有9,762场EV差朝Under移动，k2有9,796场；这是比分分布形状本身的机制，而非水位变化导致。

## 三、逆伽马特有问题还是总进球强度不确定性太大？

保持逐场Sobol后验总进球强度λ的均值、方差完全相同，用三种研究概率分布生成不同比分密度：原IG四攻防独立后验混合，匹配相同均值/方差的Gamma强度（负二项总进球），匹配相同均值/方差的对数正态强度（32点Gauss-Hermite积分）。这两种新增分布只是无收益选择的数学敏感度对照，不是已生效正式模型。

| 相同进球强度一、二阶矩下，不确定性引起的EV(Over)-EV(Under)变化 | k1 | k2 |
|---|---:|---:|
| R8原IG后验 | −0.1204007 | −0.1057239 |
| Gamma混合 | −0.1117515 | −0.0983508 |
| 对数正态混合 | −0.1169178 | −0.1028127 |

三种后验强度分布都朝Under大幅偏移，说明**主要原因是引入过大的潜在进球强度方差，而非仅逆伽马独有尾部**。这一历史样本不支持任何新的自动Under策略。

## 四、对照真实总进球：后验预测是否明显过宽

理论上，潜在进球强度λ的混合泊松总进球Var(T)=E(λ)+Var(λ)，而单一泊松Var(T)=λ。同场9,908场真实比分用于赛后校验总进球误差，没有参与研究参数重新拟合。

| 总进球方差诊断 | k1 | k2 |
|---|---:|---:|
| 真实总进球平方预测误差（使用后验样本均值） | 2.793139 | 2.755688 |
| R8后验混合预测方差 | **4.239571** | **4.023430** |
| 实际平方误差 / 后验预测方差 | **0.658826** | **0.684910** |
| R5点均值泊松实际平方误差 | 2.797132 | 2.758573 |
| R5点均值泊松理论预测方差 | 2.898135 | 2.900517 |
| 点均值泊松实际平方误差 / 预测方差 | 0.965149 | 0.951063 |

R8混合的预测方差明显偏宽。2019–2025七个赛季，k1/k2每个赛季的后验预测方差都超过当年实际总进球平方预测误差；按整赛季块抽样5,000次的全期平均“预测方差减真实平方误差”95%区间：k1［+1.279560,+1.608772］，k2［+1.111785,+1.426088］。这只是边际方差与预测误差检查，不能充当所有条件下的完整校准证明。

实际总进球≤1的频率22.5575%；k1原点均值泊松预测23.0541%，同一场同均值/方差的Gamma混合预测28.6130%；k2点均值泊松22.7269%，Gamma混合27.6119%。Gamma的低总进球率是匹配一二阶矩的敏感度参考，**不是原逆伽马混合低尾的精确值**。

结论是：在现有“指数形式xG观测＋独立逆伽马攻防”的研究假设下，后验分布积分在数学上成立，却带来了过大的预测方差，使多个盘口OU向Under变化，并造成历史整体更多亏损。不能凭此自动收缩模型方差、制定EV门槛或将某个亏损结果反打为正式模型。
