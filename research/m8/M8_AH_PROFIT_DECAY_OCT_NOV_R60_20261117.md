# M8 第60轮：AH盈利持续性退化的解剖——Crown价格还是赛果方向？

承接R59公开commit 8003accd728aeffb80949bb5f14d6d5a54703323及用户要求继续转向研究。沿用R59已经训练的Crown AH T24→T12路径与训练分数p75研究方案，不调参，不因10/11月赛果新建交易门槛或联赛白名单。只有Crown赔率用于AH盘口。原八组完全冻结且不改TG实战、账本、结算。

## 数据及限制

2024—2026年Crown历史T24/T12/T6/T1严格配对38,846场，研究每个目标年度只以前一年及更早训练，排除另存的2026真实收据目标FID进入训练。历史数据的赛前源事件时间可能是赛后回取，不能证明当时实际收到。实际收到的Crown报价来自之前已核对原始HTTP、SHA、赛事球队UTC、盘口和终场比分的2026-10-09至11-13共1,230场，其中R59路径p75研究模型选中375场（2026-10月257、2026-11月118）。此模型研究于收据与比赛结果已经存在之后，真实已收报价模拟不是事前冻结的独立前瞻，更不是Telegram真实派单或成交。

## 1. AH报酬变差的主要算术因素

| 真实已收Crown报价回放 | 2026年10月 | 2026年11月 |
|---|---:|---:|
| 研究订单数 | 257 | 118 |
| 净U | +20.210 | -4.615 |
| ROI | +7.864% | -3.911% |
| 平均所选十进制赔率 | 1.91755 | 1.91568 |
| 皇冠AH双侧倒数赔率和减1代理 | 5.618% | 5.641% |
| 主队AH方向比例 | 38.521% | 32.203% |
| AH源事件报价距采样窗口的旧龄中位 | 5.198小时 | 4.304小时 |
| 预测未来T1八组触发分数均值 | 0.30621 | 0.31148 |
| 平均结算赢注份额 | 0.49805 | 0.42373 |
| 平均结算输注份额 | 0.37549 | 0.42373 |

严格按原有Crown四分之一亚洲盘半赢、半输和走水结算，1U净收益=赢注份额×(赔率-1)−输注份额。以胜率份额、亏损份额、报价均值及赢注和报价协方差四部分构造恰好无剩余项的恒等分解。10月到11月ROI总共下跌11.77483个百分点：

| 部分（仅算术归因，不是已经证明的因果） | ROI百分点贡献 |
|---|---:|
| 平均所选赔率下降 | -0.08622 |
| 赛果对应的实际赢注份额下降 | -6.81279 |
| 赛果对应的实际输注份额增加 | -4.82424 |
| 报价与赢注协方差变化 | -0.05158 |
| 合计 | -11.77483 |

结论：当前实收回放的利润回落主要体现在比赛实际赛果与预测AH方向匹配变差，而非所选赔率变差。盘口双侧倒数和减1是报价超额代理，不是四分之一盘完整庄家利润率；不能把恒等式解读为已经确定比赛结果变化的因果来源。T1触发分数还略有升高，说明该分数尚未校准为可盈利AH的预期净回报。

## 2. 联赛构成是否解释回落？

10月375单研究集合的257场涉及40联赛，11月118场涉及36联赛；共同出现31个联赛。共同联赛10月213场、11月107场；另有10月44场、11月11场不在共同集合，全部保留在前述全量统计，不靠删除亏损场创造盈利。

在31个共同联赛里，ROI 10月+4.28169%，11月-4.99533%，共下跌9.27702个百分点。Kitagawa的同联赛内部及联赛权重恒等分解分别为-8.94204、-0.33497个百分点。联赛组合变化不能解释这批样本主要回落；但只有107场11月共同联赛记录，结果受球队、盘口和赛果波动影响，不代表各个联赛真正发生了永久性结构变化。

## 3. 不得把近期盈利月份冒充新盈利机制

2026年实收回放的11月118场只分布在6个UTC比赛日，10月257场在21个UTC比赛日。完整UTC比赛日有放回重抽5000次，11月减10月ROI差的95%经验区间[-25.348, -0.310]个百分点；区间不能消除多轮模型选择偏差，也不能推广到未观察的新比赛日期。

以前完整自然年度时间顺序训练的R59相同路径p75模型，同历史月份（赛后回取的Crown源报价，非实际实收）：

| 历史时期 | 10月 | 11月 |
|---|---|---|
| 2024 | 112场、ROI -19.393% | 86场、ROI +2.570% |
| 2025 | 63场、ROI -4.254% | 58场、ROI +2.629% |
| 2026历史回取（可能与当前实收有重叠） | 105场、ROI +5.462% | 97场、ROI -8.088% |
| 2026历史严格排除实收FID后 | 70场、ROI -1.957% | 72场、ROI -11.354% |

2024与2025历史均是10月亏、11月赢，与本次2026实收月份方向相反。因此不存在可靠的按月份扩大或停止发单的盈利规律。历史2026回取与真实实收即使同场也不算两次独立验证，不因盈利月份或已知结果增设交易Gate。

## 4. 皇冠盘口重定价、价格时效与成败方向

R59 p75选择的已收Crown报价中，10月T24→T12让球线变化组43场ROI -11.047%、11月同类19场反而+22.105%；同盘口仅水位变化组10月+10.804%、11月-4.438%；报价未变化组10月+12.761%、11月-17.441%。这种后验子组盈利方向不断反转，不能提取某个事件标签直接作为第九组。

11月的AH源事件报价旧龄中位反而比10月略短，不能简单声称因报价过期导致亏损。但源报价时间不等于收到时间或实际可成交时间；必须继续保持真实收据与历史回取区分。不同赛季、联赛、球队的隐含实力、心理信息与实际赛果仍可能是混杂因素。

## 本轮结果和建议（没有设成正式规则）

当前不存在可以确认跨年持续、独立于原八组的新增盈利AH策略。R59确实在2026年10月真实报价回放看到正利润，但目前证据更支持它是无法稳定预测真实胜负结果的模型，而非存在一个简单、可靠的Crown价格优势。

**建议/可选下一研究**：不再只预测未来价格或未来T1八组会员，改研究赛前确实已公布、带有可核查最早可得时间的独立球队实力变化，例如确认的缺阵与停赛，并比较Crown当时AH赔率是否充分反映该信息。不能拿赛后才知道的伤病、人员名单或过期的历史转会表充当前瞻信息。另一可选研究是等有新的、在本次模型确定之后才产生的真实Crown收据，再按相同模型参数盲测以检验盈利持续性；这不意味着已经设置任何自动监控或新发布Gate。
