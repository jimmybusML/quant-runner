## 第三轮：开盘到收盘价格变化是否有简单方向优势

只用开收盘已有信息按盘口变动情况进行描述，所有未变动及混合赔率变化的场次保留在分组JSON中；不是新出单条件。

- AH盘口下调8,002场：按收盘价顺着主队更强的市场移动下注，历史ROI -4.86816%，逆方向客队 -1.22676%。
- AH盘口上调7,798场：顺着客队更强的市场移动下注，历史ROI -3.65607%，逆方向主队 -2.23025%。
- OU盘口上调6,741场：顺大球历史ROI -3.48717%，逆小球 -3.23327%。
- OU盘口下调7,690场：顺小球历史ROI -3.15975%，逆大球 -3.34376%。
- 盘口不变时赔率变化、未变的记录同样入库，没有删去。所有数据属于事后回取的历史收盘源事件；在开盘时并不知道未来收盘动作，不能把此处研究说成真实可提前获得的交易收益。

**当前结果：固定方向与简单追随盘口变动在完整记录上没有直接呈现正ROI。** “反向”某些局部亏损较少，也不表示自动产生可持续盈利，未从局部数字中创建策略Gate。

## 第一轮最重要的发现

我们当前真正有用的数据资产是Codex当前实时构建的Crown盘口明细，以及同一Codex任务的赛果清单。数据量足以研究来源、盘口状态、真实赔率成本，但赛后回取的价格与真实赛前接收价不能混为同一证据。当前历史赛程缺乏与已有95场真收件相匹配的比赛/比分，是一个独立的时间/覆盖问题。这不是原先某个研究模型的结论，而是本轮从当前Codex源直接发现的事实。
